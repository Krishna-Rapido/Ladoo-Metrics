WHAT THE CAUSAL LAB DERIVES AUTOMATICALLY
PRE-PERIOD FEATURES (for PSM + HTE)
Aggregate each metric BEFORE treatment start:
• mean, std, trend slope, count of active days
• Auto-generated from your date range selection
DAILY TIME SERIES (for CausalImpact)
Aggregate to daily totals/means:
• One time series per metric per cohort
• Pre + post periods from your date config
CITY-LEVEL PANELS (for Synthetic Control)
If city column exists, aggregate per city:
• Treated city vs donor cities
• Or fetched from Presto if not in CSV
RUNNING VARIABLE (for RDD)
User selects which metric is the cutoff:
• e.g., DAPR score, ride count, online hours
• Cutoff point specified by user
Key insight: No new data upload needed. The lab derives everything from your existing captain_id x yyyymmdd x metrics schema + the pre/post date split you already configure in Insights.

The 5 Methods — When to Use Each

1. Propensity Score Matching SELECTION BIAS FIX
When: Test/control groups differ on observables (e.g., test group has more active captains)
Rapido example: "Non-daily captains" experiment — but test group happened to have more urban captains
Data needed: Your existing schema. Pre-period metrics become matching covariates automatically.
2. CausalImpact NO CONTROL NEEDED
When: City-wide rollout with no control group. Uses pre-period to predict counterfactual.
Rapido example: "New incentive structure rolled out in Bangalore" — what would have happened without it?
Data needed: Daily time series of outcome metric. Works with just test group data. Optional: control series from other cities improves accuracy.
3. Heterogeneous Treatment Effects WHO BENEFITS MOST?
When: Experiment "worked" on average — but which captains benefited most?
Rapido example: Incentive boosted rides +8% overall — but was it +20% for LP captains and -2% for HP captains?
Data needed: Your existing schema. Pre-period features become moderators. Uses Causal Forest (econml) to estimate conditional treatment effects.
4. Synthetic Control CITY-LEVEL PILOTS
When: Treatment applied to one city, need to estimate what would have happened without it
Rapido example: New surge pricing in Hyderabad — use Delhi, Chennai, Pune as "synthetic Hyderabad"
Data needed: City-level daily aggregates. Needs a "city" column in upload OR fetched from Presto. Multiple untreated cities as donors.
5. Regression Discontinuity THRESHOLD EXPERIMENTS
When: Treatment assigned based on a cutoff (captains above/below a score get different treatment)
Rapido example: "Captains with DAPR < 0.5 get a quality nudge" — is the nudge causing the improvement?
Data needed: Running variable (the score), cutoff value, outcome metric. User selects which column is the running variable.
